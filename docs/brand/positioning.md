# Arm Chat — Brand Positioning

> Grounded in the verified product: a Thai-first, calm-design chat platform on a cream canvas

---

## Brand Category

> **แพลตฟอร์มสื่อสารส่วนตัว (Private Communication Platform) ที่ออกแบบเพื่อภาษาไทยและความสงบ**

Arm Chat ไม่ใช่โซเชียลมีเดีย ไม่ใช่เครือข่ายสาธารณะ ไม่ใช่พื้นที่แชร์คอนเทนต์ แอปที่อยู่ในหมวด "สื่อสารส่วนตัว" เหมือนกลุ่มของ WhatsApp, Telegram, LINE, และ Signal — แอปที่มีไว้เพื่อคุยกับคนที่คุณรู้จัก ไม่ใช่เพื่อค้นหาคนใหม่

เราแตกต่างจากกลุ่มนี้ด้วยจุดยืนเฉพาะ: **Thai-first design + calm aesthetic** — เราไม่แข่งกับใครในแง่ของจำนวนฟีเจอร์ เราแข่งในแง่ของความรู้สึกเมื่อใช้งาน

---

## Target Users (ผู้ใช้เป้าหมาย)

### ผู้ใช้หลัก (Primary)

- **คนไทยวัย 18–40 ปี** ที่ใช้แอปแชททุกวันเพื่อคุยกับคนใกล้ตัว ครอบครัว เพื่อน และเพื่อนร่วมงาน
- รู้สึกเหนื่อยกับการแจ้งเตือนที่มากเกินไป ฟีเจอร์ที่ไม่ได้ขอ และอินเทอร์เฟซที่เปลี่ยนไปเรื่อย ๆ
- ให้คุณค่ากับภาษาไทยที่สวยงามและการออกแบบที่ใส่ใจ
- มีความกังวลเรื่องความเป็นส่วนตัวแต่ไม่อยากต้องเป็นผู้เชี่ยวชาญด้านความปลอดภัย

### ผู้ใช้รอง (Secondary)

- **ทีมและกลุ่มเล็ก ๆ ที่ต้องการพื้นที่คุยส่วนตัว** (มากกว่าจะเป็นชุมชนสาธารณะ) เช่น กลุ่มเพื่อนสนิท ครอบครัวใหญ่ กลุ่มงานเล็ก ทีมอาสาสมัคร
- **ผู้ใช้ที่ชื่นชอบการออกแบบ** — คนที่สังเกตเห็นตัวอักษร ระยะห่าง สี และรูปทรง ให้คุณค่ากับแอปที่ใส่ใจรายละเอียดเหมือนกับที่พวกเขาใส่ใจงานของตัวเอง
- **ผู้ใช้ระดับโลกที่เลือกแอปตามคุณค่า ไม่ใช่ตามความนิยม** — คนที่ใช้ Notion, Linear, Signal อยู่แล้ว และมองหาแอปแชทที่มีหลักการออกแบบเดียวกัน

---

## Brand Promise (สัญญาของแบรนด์)

> Arm Chat ช่วยให้คุณกลับมาคุยกับคนที่คุณรักได้สบายใจ — บนผ้าใบที่สงบ ภาษาไทยที่สวย และความเป็นส่วนตัวที่เป็นค่าเริ่มต้น

---

## Unique Value Proposition (จุดแตกต่าง)

### "ทำไมต้องเลือก Arm Chat แทนแอปแชทอื่น ๆ?"

| แอป | จุดเด่น | สิ่งที่ Arm Chat ทำต่าง |
|---|---|---|
| WhatsApp | ใช้งานง่าย ครอบคลุมทั่วโลก | Arm Chat ทำผ้าใบที่สงบกว่า ภาษาไทยที่สวยกว่า และไม่มีเอฟเฟกต์ที่รบกวนสายตา |
| Telegram | เร็ว ฟีเจอร์เยอะ | Arm Chat ไม่แข่งจำนวนฟีเจอร์ แต่แข่งความรู้สึกเมื่อใช้ ฟีเจอร์ที่มีคือฟีเจอร์ที่จำเป็นจริง |
| LINE | คนไทยใช้เยอะ สติกเกอร์เยอะ | Arm Chat ไม่สนสติกเกอร์ — เน้นข้อความและเสียง ขจัดความฟุ้งซ่านของสีสัน |
| Signal | ความปลอดภัยสูง | Arm Chat เคารพความเป็นส่วนตัวอย่างเดียวกัน แต่ออกแบบให้คนทั่วไปใช้ได้โดยไม่ต้องเข้าใจเทคโนโลยี |

### สามข้อที่ทำให้เราต่างจริง ๆ

1. **Thai-first โดยการออกแบบ ไม่ใช่โดยการแปล** — เราเริ่มจาก Prompt typeface + weight-400 discipline + line-height 1.4+ สำหรับสระและวรรณยุกต์ไทย เราไม่ได้แปล UI จากภาษาอังกฤษ เราออกแบบ UI จากภาษาไทยตั้งแต่ต้น

2. **Calm Utility เป็นตัวตน ไม่ใช่ธีมฤดูกาล** — ผ้าใบสีครีม `#fff8f0` ไม่ใช่เพื่อนำเทรนด์ prêt-à-porter แต่เพราะ "ถนอมสายตาในการใช้งานระยะยาว" เป็นหลักการถาวร

3. **ความเป็นส่วนตัวที่ไม่ต้องเป็นผู้เชี่ยวชาญ** — เราซ่อนความซับซ้อนของการปกป้องข้อมูลไว้หลังหน้าจอที่เข้าใจง่าย คุณไม่ต้องตั้งค่าอะไร ความเป็นส่วนตัวเป็นค่าเริ่มต้น และคุณเป็นเจ้าของข้อมูล

## Positioning Statement (ตำแหน่งในใจผู้ใช้)

>สำหรับคนไทยที่รู้สึกเหนื่อยกับแอปแชทที่เสียงดังและไม่เข้าใจภาษาของเขา **Arm Chat** เป็นแอปแชทส่วนตัวที่ออกแบบมาจากภาษาไทยเป็นหลัก บนผ้าใบที่สงบ และเคารพความเป็นส่วนตัวเป็นค่าเริ่มต้น — ไม่เหมือน WhatsApp/LINE/Telegram ที่เน้นฟีเจอร์จำนวนมากก่อนคำนึงถึงความรู้สึกของผู้ใช้
