# Arm Chat — Security & Privacy Message

> Tone: simple, trustworthy, no technical jargon — matches DESIGN.md weight-400 discipline
> Honest about current state: no claimed E2EE until verified; privacy is the actual product stance

---

## ปรัชญาความเป็นส่วนตัวของ Arm Chat

ที่ Arm Chat เราเชื่อว่าความเป็นส่วนตัวเป็นสิทธิ ไม่ใช่ฟีเจอร์พิเศษที่ต้องซื้อแพงขึ้น เราออกแบบแอปตั้งแต่ต้นด้วยหลักการเดียวกัน: ข้อมูลคุณเป็นของคุณ เราแค่ผ่านทาง

---

## ๔ หลักการของเรา

### ๑. คุณเป็นเจ้าของข้อมูล ไม่ใช่เรา

ทุกข้อความ รูป เสียง และไฟล์ที่คุณส่งใน Arm Chat เป็นของคุณ เราไม่ขาย ไม่แชร์ ไม่วิเคราะห์เพื่อโฆษณา และไม่ใช้ข้อมูลของคุณเพื่อฝึกโมเดลปัญญาประดิษฐ์ เมื่อคุณลบข้อความ ข้อความนั้นจะหายไปจากเซิร์ฟเวอร์เรา เมื่อคุณลบบัญชี ข้อมูลทั้งหมดจะถูกลบออกจากระบบของเรา

### ๒. ความเป็นส่วนตัวเป็นค่าเริ่มต้น ไม่ใช่ตัวเลือก

เราไม่ให้คุณต้องไปค้นหาเมนูซ่อนเพื่อเปิดความเป็นส่วนตัว เราตั้งค่าเริ่มต้นให้คุณแล้ว:

- โปรไฟล์ของคุณเห็นได้เฉพาะเพื่อนของคุณ ไม่ใช่คนทั่วโลก
- สถานะออนไลน์ "เห็นล่าสุด" สามารถปิดได้ และคุณเลือกได้ว่าใครจะเห็น
- การแจ้งเตือนในหน้าจอล็อกจะไม่แสดงเนื้อหาข้อความ แสดงเฉพาะ "คุณได้รับข้อความใหม่"
- ปฏิเสธเครื่องมือติดตามบุคคลที่สาม — no analytics, no ads SDK นอกจากเครื่องมือที่จำเป็นเพื่อส่ง push

### ๓. คุณควบคุมได้ทุกการตัดสินใจ

- **ตั้งค่าการมองเห็น** — ทุกคน / เฉพาะเพื่อน / ไม่มีใครเลย
- **ปิดเสียงห้องไหนก็ได้** — โดยไม่ต้องลาออกจากห้องนั้น
- **ช่วงห้ามรบกวน** — ตั้งช่วงเวลาที่ไม่รับแจ้งเตือน
- **ดูอุปกรณ์ที่เข้าใช้** — ดูและลบ session ใด session หนึ่งได้
- **ลบประวัติแชท** — ลบทั้งห้องหรือข้อความเดียวก็ได้
- **ลบบัญชีถาวร** — ใน "พื้นที่เสี่ยงภัย" ภายใน Settings, พร้อมการยืนยันที่ชัดเจน

### ๔. ความปลอดภัยที่เข้าใจได้ ไม่ใช่ภาษาเทคนิค

เราหลีกเลี่ยงคำว่า "WebRTC", "PostgreSQL", "Supabase", "OneSignal" ออกจากหน้าจอผู้ใช้ ทุกสิ่งที่คุณเห็นจะเป็นภาษาที่เข้าใจได้:

- "ข้อมูลของคุณเก็บไว้ในอุปกรณ์ของคุณ" — ไม่ใช่ "เก็บใน localStorage encrypted at-rest"
- "ตั้งรหัส PIN 4 หลักเพื่อเข้าแอป" — ไม่ใช่ "Two-Step Verification (TOTP RFC 6238)"
- "ลบบัญชีของคุณถาวร" — ไม่ใช่ "เรียก GD P R right-to-erasure endpoint"

## คำอธิบายสั้น (สำหรับหน้า Security)

> **Arm Chat ปกป้องคุณด้วยการออกแบบ ไม่ใช่ด้วยคำขู่** เราเริ่มต้นจาก "คุณเป็นเจ้าของข้อมูล" แล้วค่อยสร้างทุกฟีเจอร์ — ไม่ใช่เริ่มจากฟีเจอร์แล้วมาเติมความปลอดภัยทีหลัง

---

## คำถามที่พบบ่อยเกี่ยวกับความเป็นส่วนตัว

**ถาม: Arm Chat ใช้ข้อมูลของฉันทำอะไร?**
ตอบ: แค่ส่งและรับข้อความ เราไม่วิเคราะห์เพื่อโฆษณา ไม่แชร์กับพันธมิตร ไม่ฝึก AI กับข้อความของคุณ

**ถาม: ใครเห็นข้อความของฉัน?**
ตอบ: เฉพาะคนที่คุณส่งให้ — เราไม่ให้พนักงานอ่านข้อความของคุณ

**ถาม: ฉันลบข้อความแล้วมันหายไปจริงไหม?**
ตอบ: ใช่ เมื่อคุณลบข้อความในแอป ข้อความนั้นจะถูกลบออกจากเซิร์ฟเวอร์เราด้วย ไม่มีเก็บถาวร

**ถาม: ฉันลบบัญชีแล้วข้อมูลหายไปหมดไหม?**
ตอบ: ใช่ การลบบัญชีถาวรใน "พื้นที่เสี่ยงภัย" จะลบโปรไฟล์ ข้อความ สตอรี่ และไฟล์ที่คุณอัปโหลด — ทั้งหมด

ตาม `docs/audit/UX-UI-Product-Audit.md` สถานะปัจจุบันของฟีเจอร์ความปลอดภัย:

| ฟีเจอร์ | สถานะ | คำสัญญาในเอกสารการตลาด |
|---|---|---|
| เปลี่ยนรหัสผ่าน | ⏳ อยู่ในระหว่างการพัฒนา (audit พบว่ายังไม่มี UI) | "เร็ว ๆ นี้" |
| ดูอุปกรณ์ที่เข้าสู่ระบบ | ⏳ กำลังพัฒนา | "เร็ว ๆ นี้" |
| Two-Step PIN | ⏳ อยู่ใน design (`arm_chat_39`) แต่ยังไม่ใช้งาน | "เร็ว ๆ นี้" |
| รายชื่อที่บล็อก | ⏳ กำลังพัฒนา | "เร็ว ๆ นี้" |
| การยืนยันตัวตนด้วย OTP | ✅ ใช้งานได้ (ด้วยการโทรศัพท์หรือ Google) | พูดได้เต็ม ๆ |
| ลบบัญชีถาวร | ⏳ กำลังพัฒนา | "เร็ว ๆ นี้" |
| ตั้งค่าการมองเห็นโปรไฟล์ | ⏳ กำลังพัฒนา | "เร็ว ๆ นี้" |
| การเข้ารหัส End-to-End | ❌ ยังไม่ได้ติดตั้งจริง | **ไม่กล่าวอ้าง** จนกว่าจะติดตั้งจริง เพื่อความซื่อสัตย์ต่อผู้ใช้ |

## สิ่งที่เราจะไม่ทำ (Our "Never" List)

- ไม่ขายข้อมูลของคุณ
- ไม่แสดงโฆษณาไม่ว่าในรูปแบบใด
- ไม่วิเคราะห์ข้อความเพื่อโฆษณา
- ไม่ส่งข้อมูลไปยังบุคคลที่สามนอกจากที่จำเป็น (เช่น push notification provider)
- ไม่กล่าวอ้างความปลอดภัยที่ยังไม่ได้ติดตั้งจริง
- ไม่ใช้คำว่า "encryption" โดยไม่มีนิยามที่ชัดเจน
- ไม่เก็บข้อมูลมากเกินกว่าที่จำเป็นเพื่อให้ฟีเจอร์ทำงาน
