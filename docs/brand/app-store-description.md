Arm Chat คือแอปแชทส่วนตัวที่ออกแบบจากภาษาไทยเป็นหลัก บนผ้าใบสีครีมอุ่นที่สงบ และเคารพความเป็นส่วนตัวเป็นค่าเริ่มต้น 🌿

ทำไมต้องเลือก Arm Chat?

✦ **ภาษาไทยที่สวยงาม**
เราใช้ตัวอักษร Prompt ที่ออกแบบสำหรับภาษาไทยโดยเฉพาะ ด้วย weight 400 เท่านั้น — ทุกตัวอักษรอ่านสบายตา สระและวรรณยุกต์แสดงผลได้อย่างสมบูรณ์

✦ **ความสงบที่ใช้งานได้จริง**
ผ้าใบสีครีม `#fff8f0` ที่ถนอมสายตา สีเขียวเดียวสำหรับสิ่งที่สำคัญที่สุด และเส้นขอบบางแทนเงา — ทุกสิ่งถูกออกแบบให้สงบและเข้าใจง่าย

✦ **ความเป็นส่วนตัวเป็นค่าเริ่มต้น**
เราไม่ขายข้อมูลคุณ ไม่แสดงโฆษณา ไม่วิเคราะห์เนื้อหาข้อความ คุณเป็นเจ้าของข้อมูลและควบคุมทุกการตัดสินใจ

✦ **ฟีเจอร์ครบ**

📱 **แชทและกลุ่ม**
